Alpha Radar V21.0 母池＋因子權重研究室

這是獨立研究程式，不是 V20.3.1 的覆蓋修正包。
請使用新的 GitHub repository / Streamlit app，保留舊版與 data/。
不要把舊版的 v19_results.json 當成全市場歷史資料。

1. 部署
解壓縮後，將全部程式放在同一個根目錄。
Streamlit 入口選 app.py；Python 3.11 / 3.12。
依賴套件由 requirements.txt 安裝。
本機執行：
  python -m pip install -r requirements.txt
  streamlit run app.py

2. 啟動
預設模式為自動取得現行官方公司名冊及歷史量值。
按一次啟動／繼續，自動完成各步驟；不用切 S1/S2 或 A/B。
資料儲存於 data/v21_universe_lab/，不影響舊版資料。
初次全市場下載可能需數小時；程式會顯示進度與 API 等待。
可選擇在 Streamlit Secrets 設定 FINMIND_TOKEN，不要放進公開程式碼。
主機休眠或重啟不保證繼續執行；資料仍在時，重開後可按繼續。
初次大量下載建議使用不會休眠的本機或持續運作主機。

3. 比較內容
每月依過去252個交易日實際成交金額，選出前100/200/300/500檔。
同一批日期、同一成本與基準，比較母池與因子權重。
預設14個價量因子、64組有限候選；5/20/60日分別挑選。
只在訓練期選擇母池與權重，再用之後時段檢查。
最後24個月不參與選模型，不會因為失敗就自動改權重。
市值、營收、EPS與法人因子需有公告時點的額外輸入，不會假補資料。

4. 報告
優先直接讀取 REPORT.txt，不需解壓縮。
selected_models.json：各週期挑出的母池與權重。
results.json：訓練、外層驗證、最後期間與資料限制。
LAB_RESULTS.zip：小型報告包，不夾帶大量原始價格。
下載不會重跑研究。完成後不自動加測。

5. 必要限制
現行官方名冊不是完整歷史成分名冊，預設仍有倖存者偏差。
舊的150檔報告不能代替全市場量值。
已曝光的歷史時段不會因分割而變成真正未來盲測。
選出的是「有限候選中的訓練優選」，不是保證獲利或全域最佳。
本次完成工程與合成資料測試；尚未產生真實全市場績效結果。
不會自動下單。詳細方法及限制請閱 README.md / PROTOCOL.md / QA_STATUS.md。
